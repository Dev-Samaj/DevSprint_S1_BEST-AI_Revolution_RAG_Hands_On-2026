# Contributing to the Workshop Repository

Welcome to the Dev Samaj BEST AI RAG Workshop repository.

Every participant is welcome to submit their workshop project.

## Submission Process

### 1. Fork this repository

Click **Fork** at the top-right of this repository.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/BEST-AI-RAG-Workshop.git
cd BEST-AI-RAG-Workshop
```

### 3. Create a branch

```bash
git checkout -b submission-YOUR-USERNAME
```

### 4. Create your submission folder

Create:

```text
submissions/YOUR-GITHUB-USERNAME/
```

Example:

```text
submissions/sunitpanda/
```

### 5. Add your project

Put your project files inside your folder.

Example:

```text
submissions/sunitpanda/
├── README.md
├── app.py
├── requirements.txt
└── ...
```

### 6. Add your project README

Your `README.md` should contain:

- Your name
- Your GitHub username
- Project name
- Short project description
- Technologies used
- What you completed
- What you could not complete
- How to run the project

### 7. Commit your work

```bash
git add .
git commit -m "Add RAG project - YOUR-USERNAME"
```

### 8. Push

```bash
git push origin submission-YOUR-USERNAME
```

### 9. Create a Pull Request

Open your fork on GitHub and click:

**Compare & pull request**

Create the PR against:

```text
Dev-Samaj/BEST-AI-RAG-Workshop
```

### 10. Wait for Review

The Dev Samaj team will review your submission.

If accepted, your project will be merged into the repository.

Your project will then appear here:

```text
submissions/YOUR-GITHUB-USERNAME/
```

## Important Rules

- Use your own GitHub username as the folder name.
- Do not modify other participants' submissions.
- Do not delete existing projects.
- Do not upload passwords, API keys or secrets.
- Do not commit `.env` files.
- Submit only workshop-related work.
- One participant should use one submission folder.

## Partial Projects

You can submit even if your project is incomplete.

You can submit:

- Fully completed project
- Partially completed project
- Basic implementation
- Experimental implementation

Clearly mention your completion status in your project README.

Happy building! 🚀

**Dev Samaj**
